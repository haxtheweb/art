The proposal is CC BY 4.0 for art HAX created; see LICENSING.md. Some World Traveler variants riff on other creators' work. Those aren't shown on this site; they are flagged in manifest.json for review before promotion.

Hotlinking

Every image on this site is a raw GitHub URL, such as https://raw.githubusercontent.com/haxtheweb/art/main/world-traveler/funny-traveler-15.png. File names in the repo are never renamed, so these links stay stable.

How this was made

Most World Traveler variants are AI-generated remixes of the original human-made character. RPG Glitch, the HAX the Web game, the wanted poster and HAX in under a minute were made with an AI assistant (Claude) under HAX team direction. HAX's own writing and brand marks are not AI-generated.

Add to the collection

Open a pull request on haxtheweb/art; AGENTS.md has the rules. To refresh this site after adding World Traveler variants, run node tools/hax-art-items.mjs and import the result with the HAX CLI.
