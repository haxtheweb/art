Hotlinking
----------

Every image on this site is a raw GitHub URL, such as `https://raw.githubusercontent.com/haxtheweb/art/main/world-traveler/funny-traveler-15.png`. File names in the repo are never renamed, so these links stay stable.

How this was made
-----------------

Most World Traveler variants are AI-generated remixes of the original human-made character. The interactive pieces (RPG Glitch, the HAX the Web game, HAX of the Web, the wanted poster, HAX in under a minute, the opening titles and Episode XXVI) were made with an AI assistant (Claude) under HAX team direction. HAX's own writing and brand marks are not AI-generated.

Add to the collection
---------------------

Open a pull request on [haxtheweb/art](https://github.com/haxtheweb/art); [AGENTS.md](https://github.com/haxtheweb/art/blob/main/AGENTS.md) has the rules. To refresh this site after adding World Traveler variants, run `node tools/hax-art-items.mjs` and import the result with the HAX CLI.
