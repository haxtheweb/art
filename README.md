# art

Artwork for **[HAX](https://haxtheweb.org)**: open-source tools that let anyone create, remix and publish on the web without needing to understand the web.

![The Future Traveler in 36 variants](future-traveler/contact-sheet.jpg)

## Meet the Future Traveler

HAX's official mascot: a red-helmeted, steampunk-goggled time traveler who traveled to the future to bring our ideas to life. He collects the best ideas of every era and carries them into the future, where data flows like water. **Dream it, remix it, have it, share it.** Read his story and character sheet in [`future-traveler/`](future-traveler/README.md).

## Using the art

Attribution: **HAX (haxtheweb), https://github.com/haxtheweb/art**. Please read [`LICENSING.md`](LICENSING.md): some variants are parodies of other people's work and need extra care.

Hotlinking? Use raw URLs like `https://raw.githubusercontent.com/haxtheweb/art/main/future-traveler/funny-traveler-15.png`. File names are kept stable; renames are rare and announced in the commit history.

## Contributing

Open a pull request. Add new variants as the next numbered file and add a [`manifest.json`](manifest.json) entry. See [`AGENTS.md`](AGENTS.md) for the rules. The project's [contributing guide, code of conduct and CLA](https://github.com/haxtheweb) apply.
