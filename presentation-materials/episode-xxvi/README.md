# HAX Episode XXVI: Return of the Open Web

A space-opera opening crawl that catches people up on HAX: where it came from, the web standards it stands on, and where the journey is in 2026 (version 26). It is a playful riff on the classic sci-fi opening crawl, cast as the Rebellion against the **Edtech Empire** and the **Silicon Valley hosting overlords**. It ends on a "Join the Rebellion" card linking to [hax.psu.edu](https://hax.psu.edu).

## The crawl text

> **Episode XXVI: RETURN OF THE OPEN WEB**
>
> It is a period of walled gardens. For nearly a decade, rebel developers striking from a hidden repository in Happy Valley have waged war against the EDTECH EMPIRE, whose LMS fortresses lock knowledge behind licenses, logins and proprietary formats that die the moment the contract does.
>
> Across the galaxy, the SILICON VALLEY HOSTING OVERLORDS tighten their grip, renting creators back their own words by the month and turning every humble website into a subscription with a dashboard and an upsell.
>
> Armed only with WEB STANDARDS, the Rebellion forged HAX. Web Components that run in any browser. Plain HTML anyone can read. JSON Outline Schema to give every site a spine. OER Schema so learning can be found and remixed. WCAG accessibility in every block. Sites that are portable, remixable, static-capable and *owned*. All of it Apache-2.0. None of it rented.
>
> Now, in the year twenty-six, version 26 rolls off the line and the Rebellion advances on every front. The DDD design system unites themes and admin screens under one language. A new plugin architecture lets the core keep raising the baseline, so no old site is left behind. Lit SSR and AI-readiness make what creators build visible to humans and agents alike. Learn HAX rises to train new recruits, in 102 languages.
>
> The Empire's plan depends on content being trapped. The Rebellion's plan is simpler: humans and AI remixing each other's work, accessibly, on the open web, with no one holding the keys but the people who made it.
>
> As the overlords count their recurring revenue, a small band of educators, designers and developers gathers at the Rebellion's base, preparing to welcome anyone brave enough to publish something they actually own....

## Provenance

Built by Claude (an AI assistant) as one HTML page, with direction from the HAX team. Not hand-drawn or hand-composed.

- **Third-party reference:** the format deliberately parodies the opening crawl of the *Star Wars* films (the "Episode" numbering, the tilted gold text crawling into a starfield, the "not so long ago" intro line). It copies no footage, logo or artwork from those films; the text is original.
- **Music:** an original fanfare written for this page and synthesized live in the browser with the Web Audio API (sawtooth "brass", strings, timpani, snare, cymbal). It does not quote the *Star Wars* score. No audio files are included.
- **Type:** [Saira](https://fonts.google.com/specimen/Saira), Saira Condensed and Saira Extra Condensed from Google Fonts (open-licensed), loaded at runtime with system fallbacks.

Because it parodies a third-party work, review it before using it in official or paid promotion (see [`LICENSING.md`](../../LICENSING.md)).
