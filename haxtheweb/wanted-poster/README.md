# WANTED: HAX, the Open Web Outlaw

An old-west wanted poster starring the HAX [`rpg-character`](https://github.com/haxtheweb/webcomponents/tree/main/elements/rpg-character) in its cowboy hat. Instead of a cash bounty, the reward is $0, because the source is already free for anyone who wants to fork it.

## Provenance

Rendered procedurally by Claude (an AI assistant) in Python, not hand-drawn. The character is assembled from the `rpg-character` element's own SVG layers (cowboy hat, sunglasses, bolo tie), then printed as a line-engraving halftone. The parchment, stains, folds, ink wear and torn edges are generated noise. Type is set in [Alfa Slab One](https://fonts.google.com/specimen/Alfa+Slab+One) and [Roboto Slab](https://fonts.google.com/specimen/Roboto+Slab) (both open-licensed). The layout riffs on the generic western wanted-poster genre; it copies no specific third-party artwork.
